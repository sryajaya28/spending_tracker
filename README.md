# Stiver

A simple personal finance app: record and categorize spending, track monthly budgets, and see your whole net worth
(savings, investments, money you lent, and loans you owe) in one place.

Live at **https://stiver.io**. A static browser app (`prototype/`) on Vercel, with Supabase for sign-in and data.
See `context.md` for the full project context (architecture, services, decisions, open items).

## What it does

- **Landing page and accounts:** one-page landing with a demo video; sign up with email (confirmation link) or Google.
- **USDT/USDC:** receive income into, or pay expenses from, a stablecoin in your investment account.
- **Indonesian stocks and commodities:** IDX tickers (BBCA, BBRI...) plus gold, silver and oil, priced live from Yahoo Finance (unofficial source).
- **Recurring:** repeat an expense, income, transfer or investment buy every week or month (added when you open the app).
- **Transactions:** a daily summary (one row per day); click a day for its detailed transactions. Expenses and income with categories and sub-categories, multi-currency wallets, AI-style auto-tagging
  that stays uncategorized when unsure, and categories you can add right from the transaction form.
- **Budgets:** overall and per-category monthly budgets (ok / warning / exceeded) and **special occasions** (a one-off
  budget such as "Bali Trip") that you tag expenses to.
- **Portfolio** (four tabs): Savings (wallets, transfers between wallets with an optional fee), Investment (crypto, US
  stocks and ETFs with live Finnhub prices, buys and sells), Lent (money others owe you), Loan (debts you owe).
- **Net worth** with month-over-month growth in your preferred currency (IDR, USD, EUR, GBP, SGD, AUD, JPY).
- **English and Bahasa Indonesia**, and **light / dark / match-device** appearance, both saved to your account.
- **Sample data** is a switch in Settings: a demo account in memory that never touches your real data. It is localized to the reporting currency (IDR, SGD, HKD, JPY, USD, EUR, GBP, AUD, CNY; others use USD) with local banks, e-wallets, merchants, brokers and stocks.

## Run it locally

Requires Python 3. No Node needed to run the app.

```bash
cp .env.example .env.local     # put your Finnhub key after FINNHUB_API_KEY= (optional)
python3 tools/dev_server.py 5173
```

Open http://localhost:5173. The dev server serves `prototype/` and proxies Finnhub so the key stays server-side.
Without a key the app still works with built-in demo assets. Signing in uses the real Supabase project configured in
`prototype/config.js`; add `http://localhost:5173` to the redirect URLs in Supabase to use Google sign-in locally.

## How it is built

| Part | Where |
|---|---|
| App (single-page, no build step) | `prototype/` (`app.js` UI, `cloud.js` sign-in + data sync, `i18n*.js` translations + theme) |
| Landing page, privacy policy, terms | `prototype/app.js` (landing), `prototype/privacy.html`, `prototype/terms.html` |
| Hosted API for live prices | `api/index.py` (Vercel function reusing `tools/dev_server.py`) |
| Hosting config + security headers | `vercel.json` |
| Database (tables, RLS, functions) | `supabase/migrations/` (13 files, in order) |
| Auth email templates | `supabase/templates/` (generated by `tools/build_email_templates.py`) |
| Browser tests | `tests/e2e/` (`bash tests/e2e/run_all.sh`) |

Saving is diff-based: every change is mapped to database rows, compared with the last known server state, and only
changed rows are sent. Row-level security means a signed-in user only ever sees their own rows.

## Deploying

Pushing to `main` deploys to production on Vercel. `FINNHUB_API_KEY` lives only in the Vercel project's environment
variables. Database changes are SQL files in `supabase/migrations/` and are applied to the Supabase project (the repo
file names and the version numbers recorded in Supabase differ, so do not run `supabase db push` blindly).

Supabase dashboard settings the app relies on: Email provider with **Confirm email** on, Google provider enabled,
URL Configuration (Site URL `https://stiver.io`, redirect URLs include `https://stiver.io/**` and `http://localhost:5173/**`),
custom SMTP (Resend, sender on `stiver.io`), and the templates in `supabase/templates/`.

## Before wider release

- Finnhub's free plan is for personal use. A public product needs a suitable plan or another data source.
- Turn on CAPTCHA (Turnstile): set `TURNSTILE_SITE_KEY` in `prototype/config.js` and enable it in Supabase together.
- Set a minimum password length of 8 in Supabase and turn on two-factor sign-in on your Supabase, Vercel, GitHub and Google accounts.
- Add a staging environment (separate Supabase project + `staging` branch).
- Add a license, and set `CONTACT_EMAIL` in `prototype/config.js` for the privacy and terms pages.
- Never commit secrets. Only the public Supabase key and Turnstile *site* key belong in this repo.
