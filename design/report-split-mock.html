What changed

  • Overview keeps one job: today. Budget line and bar, Money Flow, Spending and Category trend are gone from it.
  • Today list shows every item from today, including income and transfers. The big number counts expenses only, as now.
  • Missing days sit below today's list: a 7-day strip, then one row per empty day with Add and Nothing to add.
  • Report replaces Transactions in the bar. Transactions | Analysis is a switch at the top of the page.
  • Budgets tab is gone. Its whole page lives in Analysis, so the bar is Overview, Report, Add, Portfolio.

Rules behind frame 1

  • A missing day is one of the last 7 days (today excluded) with no transaction of any kind. Recurring entries count.
  • Days before the first transaction are never flagged, so a new account starts quiet.
  • Nothing to add is remembered on this device only (no database change). The day turns grey in the strip and the row goes away.
  • Tapping Add, or a dashed day in the strip, opens Add transaction already dated to that day.
  • No missing days: the card becomes the single green line in frame 4.

Please look at

  • Add button position. With three tabs, Add sits between Report and Portfolio, off centre. A floating Add button is the alternative.
  • Analysis order. Budget, categories, occasions, Spending, Category trend, then Money Flow. Money Flow was not in your list, so it comes last.
  • Report remembers the month you pick, and the same month applies to both pages.
  • Not drawn: an optional "no transactions" marker for empty days inside the Transactions list.
