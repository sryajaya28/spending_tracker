## 5. Figma / tool notes (things that cost time)
- `get_screenshot` URLs cannot be downloaded in the sandbox (figma.com blocked). Screenshot inside `use_figma` with `await node.screenshot({scale})`: clone the frames into a temporary auto-layout "TEMP sheet" placed at x=-9000, screenshot it, remove it. Always check no `TEMP` node is left (the sanity pass does).
- `Inter` styles are `Regular`, `Medium`, `Semi Bold`. Load every font used by a node (`getStyledTextSegments`) before editing text.
- `layoutPositioning = 'ABSOLUTE'` works only when the parent is auto-layout. The Add transaction frames are plain clipped frames (position with x/y); Overview and Report frames are auto-layout (appending a child puts it in the flow unless set absolute).
- The Overview/Report/Budgets/Portfolio frames came from imported HTML: controls are named `Button...`/`Link...`, not `ctl:`; frames I built by hand name controls `ctl: <label>` so a script can measure 44px targets. Keep that convention.
- Reusable measuring script pattern (overflow vs frame box, text inside parent, contrast against the nearest solid fill, `ctl:` under 44px, nav check): see the sanity pass in this session; rebuild it in one `use_figma` call, return only counts and the first few offenders.
- Rounding of tap areas: the visible pill may be smaller than 44px when its tap area is 44px (eye, currency selector, `Rp` prefix box); say so in the component spec.
