# Feature tests

One entry per feature. The owner can add entries at any time ("also test X"); the session adds the steps, runs them and records the result. A feature is **ready for review** only when its entry passes. Every entry also checks the feature's event tracking (`docs/ANALYTICS.md`).

| Field | Meaning |
|---|---|
| Should | what the feature must do, in the owner's words |
| Steps | how to try it by hand |
| Expected | what you see when it works |
| Covered by | the automated test file, or "manual" |
