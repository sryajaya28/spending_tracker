# Where this setup came from

This repository was set up from the owner's **starter kit** (version in `tools/kit.config.json`, `kitVersion`): the workflow, tier rules, tools, templates and carried-over lessons from earlier projects. Source: __KIT_HOME__.

## Sending lessons back
When a lesson here would help any project (not only this one), add it to the matching file in the kit's `template/docs/learning/` in a small PR to the kit repository, in the same words. Improved tools and workflow rules go back the same way. That is how the next project starts smarter than this one.

## Taking updates
To pull a newer kit into this repository: `bash <kit>/install.sh . --update` copies kit files that are missing here and lists the ones that differ, without overwriting anything. Merge those by hand.
