# Learning: mistakes made, and how to avoid them

Every item cost time, broke something, or annoyed the owner. **This file is an index**: load only the area files your task needs. The area files start with the lessons carried over from earlier projects (starter kit); add this project's own below them.

| Your task | Load these (in `docs/learning/`) |
|---|---|
| Any change, always | `owner.md` (how the owner works) |
| About to push, merge, release or deploy | `release.md` |
| Database, migrations, access rules, sync, server functions | `data.md` |
| Editing app code, event tracking | `code.md` |
| Layout, styles, phone and browser behaviour, dark mode | `ui.md` |
| Writing or running tests, smoke tests | `testing.md` |
| Cloud session tools (git, GitHub, proxy, connectors) acting strangely | `cloud.md` |
| Planning a long task, splitting work, anything about sessions and cost | `cost.md` |
| Tier 1 (presentation only) | `owner.md`, `ui.md` |
| Tier 3 (data, access, money) | `owner.md`, `release.md`, `data.md`, `testing.md` |

**At the end of every session** append what you learned to the Session log below (mistakes, owner corrections, surprises, detours), and add a short lasting rule to the right area file when it applies beyond that session. Keep each item short and say what to do instead. `node tools/trim_learnings.js` moves old log entries to `docs/learning-archive.md`.
