# Email templates

Generated by `python3 tools/build_email_templates.py`. Edit the script, not the HTML.

Paste each file into **Supabase > Authentication > Emails > Templates** (open the template, set the subject, replace the message body with the file's HTML, save).

| Supabase template | Subject | File |
|---|---|---|
| Confirm sign up | `Confirm your email to get started with Stiver` | `confirmation.html` |
| Reset password | `Reset your Stiver password` | `recovery.html` |
| Magic link | `Your Stiver sign-in link` | `magic_link.html` |
| Change email address | `Confirm your new Stiver email address` | `email_change.html` |
| Invite user | `You’ve been invited to Stiver` | `invite.html` |
| Reauthentication | `Your Stiver security code` | `reauthentication.html` |

Variables used: `{{ .ConfirmationURL }}`, `{{ .Email }}`, `{{ .NewEmail }}`, `{{ .Token }}`.
Sender name/address are set under **Authentication > SMTP Settings** (e.g. Stiver, noreply@stiver.io).
